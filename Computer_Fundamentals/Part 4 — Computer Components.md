# 04. Computer Components

### Understanding the Components That Connect, Power, and Cool a Computer

A computer contains several hardware components that work together.

In this section, we will focus on three important components:

1. Motherboard
2. Power Supply Unit (PSU)
3. Cooling System

---

## 1. Motherboard

The **Motherboard** is the main circuit board of a computer.

It connects different hardware components and provides the pathways through which they communicate.

### 1.1 Main Responsibilities

- Connects the CPU, RAM, storage, and other components.
- Provides communication pathways between components.
- Distributes power to connected components through its power circuitry.
- Provides connectors and expansion slots for additional hardware.

### 1.2 Examples of Components Connected to a Motherboard

- CPU
- RAM
- GPU
- SSD
- Cooling system
- USB devices

### Simple Diagram

```text
       +--------------------------+
       |       MOTHERBOARD        |
       |                          |
       |   +------+   +-------+   |
       |   | CPU  |   |  RAM  |   |
       |   +------+   +-------+   |
       |                          |
       |   +------+   +-------+   |
       |   | GPU  |   |  SSD  |   |
       |   +------+   +-------+   |
       |                          |
       +--------------------------+
```

### Real-Life Example

Think of the motherboard as a communication platform.

The CPU, RAM, GPU, and storage are different components. The motherboard provides the connections that allow them to communicate and work together.

**Remember:** The motherboard connects components; it does not independently decide what each component should do.

---

## 2. Power Supply Unit (PSU)

The **PSU (Power Supply Unit)** provides the electrical power required by computer components.

A desktop PSU converts electricity from the wall outlet (AC) into regulated DC power that computer components can use.

### 2.1 Main Responsibilities

- Receives electrical power from the wall outlet.
- Converts AC electricity into DC electricity.
- Regulates output voltages.
- Supplies power to components such as the motherboard, CPU, GPU, and storage devices.

### 2.2 Real-Life Example

Imagine a desktop computer with:

- CPU
- GPU
- Motherboard
- RAM
- SSD
- Cooling fans

All these components require electrical power.

The PSU supplies the appropriate power to the computer's components.

### Important Note About Laptops

Most laptops use an external power adapter to convert AC power into DC power. The laptop's internal power circuitry then manages power distribution and battery charging.

**Remember:** The PSU or power adapter provides electrical power. It does not process program instructions.

## 3. Computer Cooling System

Computer components such as the CPU and GPU generate heat while operating.

If excessive heat builds up, performance may decrease and hardware may become damaged.

A cooling system helps maintain safe operating temperatures.

Two important cooling components are:

### 3.1 Heat Sink

A heat sink is a component designed to absorb and spread heat away from a hot component.

It is usually made from materials with good thermal conductivity, such as aluminum or copper.

**Example:** A CPU heat sink absorbs heat from the CPU and spreads it across its metal fins.

### 3.2 Fan

A fan moves air through the computer.

It helps carry heat away from the heat sink and other components.

**Example:** A CPU cooling fan blows air across the heat sink to improve heat removal.

### Heat Sink vs. Fan

| Heat Sink | Fan |
|---|---|
| Absorbs and spreads heat | Moves air |
| Usually made of metal | Uses a rotating motor and blades |
| Transfers heat away from the component | Helps remove warm air |
| Does not necessarily require electricity | Requires electricity |

### How They Work Together

```text
       CPU GENERATES HEAT
                |
                v
           +-----------+
           | HEAT SINK |
           +-----------+
                |
                v
        FAN MOVES AIR
                |
                v
       HEAT LEAVES THE AREA
```

**Remember:** The heat sink transfers and spreads heat; the fan moves air to help remove that heat.

## 4. Key Takeaways

| Component | Main Function |
|---|---|
| Motherboard | Connects hardware components |
| PSU | Supplies regulated electrical power |
| Heat Sink | Absorbs and spreads heat |
| Fan | Moves air to help remove heat |

- The motherboard provides connections and communication pathways.
- The PSU supplies electrical power to computer components.
- The heat sink transfers and spreads heat away from hot components.
- The fan moves air to help remove heat.
- Cooling is important for maintaining safe operating temperatures.
