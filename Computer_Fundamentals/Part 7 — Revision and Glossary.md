# 1. Important Comparisons

## 1.1 RAM vs. ROM

| RAM | ROM |
|---|---|
| Temporary working memory | Non-volatile memory category |
| Volatile | Non-volatile |
| Stores active program data and instructions | Traditionally stores persistent instructions/data |
| Used during normal program execution | Commonly associated with firmware storage |

## 1.2 RAM vs. Cache

| RAM | Cache |
|---|---|
| Larger capacity | Much smaller capacity |
| Slower than CPU cache | Faster than RAM |
| Holds active programs and data | Holds copies of useful data and instructions |
| Used by the overall system | Helps the CPU access information faster |

## 1.3 SSD vs. RAM

| SSD | RAM |
|---|---|
| Long-term storage | Temporary working memory |
| Non-volatile | Volatile |
| Keeps data after shutdown | Loses data without power |
| Stores applications and personal files | Holds information needed by running applications |

## 1.4 CPU vs. GPU

| CPU | GPU |
|---|---|
| General-purpose processor | Specialized graphics and parallel processor |
| Executes a wide variety of instructions | Handles many parallel operations efficiently |
| Runs general program logic | Commonly handles graphics and demanding parallel workloads |

## 1.5 Input vs. Output Devices

| Input Devices | Output Devices |
|---|---|
| Send data to the computer | Present information from the computer |
| User → Computer | Computer → User |
| Keyboard, mouse, microphone | Monitor, speaker, printer |

## 1.6 Heat Sink vs. Fan

| Heat Sink | Fan |
|---|---|
| Transfers and spreads heat | Moves air |
| Usually metal | Rotating mechanical component |
| Helps conduct heat away | Helps remove warm air |

# 2. Key Takeaways

| Component | Main Function |
|---|---|
| CPU | Executes program instructions |
| Control Unit | Coordinates instruction execution |
| ALU | Performs arithmetic and logical operations |
| Registers | Hold immediately needed CPU data |
| RAM | Temporary working memory |
| ROM | Non-volatile memory category |
| Firmware | Initializes and controls hardware |
| Cache | Provides faster access to useful data and instructions |
| HDD | Long-term magnetic storage |
| SSD | Long-term flash storage |
| Motherboard | Connects hardware components |
| GPU | Handles graphics and parallel processing |
| PSU | Supplies regulated electrical power |
| Heat Sink | Absorbs and spreads heat |
| Fan | Moves air to help remove heat |
| Input Devices | Send information to the computer |
| Output Devices | Present information to the user |

### The Most Important Memory Distinction

```text
SSD   = Permanent Storage
RAM   = Temporary Working Memory
CACHE = Fast CPU-Accessible Memory
CPU   = Executes Instructions
```

### The Basic Computer Working Model

```text
INPUT → PROCESSING → OUTPUT
```

And during startup and program execution:

```text
POWER → FIRMWARE → OS BOOT → RAM + CPU → APPLICATION
```

# 4. Glossary

Important technical terms and their meanings.

| Term | Meaning |
|---|---|
| Computer | An electronic device that processes data |
| Hardware | Physical components of a computer |
| Software | Programs and instructions |
| CPU | Central Processing Unit |
| GPU | Graphics Processing Unit |
| RAM | Random Access Memory |
| ROM | Read-Only Memory |
| SSD | Solid State Drive |
| HDD | Hard Disk Drive |
| PSU | Power Supply Unit |
| OS | Operating System |
| Firmware | Low-level software used to initialize or control hardware |
| Cache | Small, fast memory used by the CPU |
| Register | Very fast storage location inside the CPU |
| Motherboard | Main circuit board of a computer |
| Input | Data provided to a computer |
| Output | Information produced by a computer |
| Processing | Executing operations on data |
| Storage | Keeping data for future use |
| Booting | Starting the computer and loading its operating system |
| UEFI | Unified Extensible Firmware Interface |
| POST | Power-On Self-Test |
| VRAM | Video Random Access Memory |
| Volatile | Memory that generally loses its contents without power |
| Non-volatile | Memory that retains its contents without power |
