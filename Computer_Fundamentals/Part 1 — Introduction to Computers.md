# 01. Introduction to Computers

### Understanding the Basic Concepts of a Computer System

## 1. What Is a Computer?

A **computer** is an electronic device that accepts data, processes it according to instructions, stores information, and produces meaningful output.

In simple words, a computer takes input, works on it, and gives us a result.

### The Four Basic Functions of a Computer

| Function | Meaning | Example |
|---|---|---|
| Input | Receiving data or instructions | Typing numbers |
| Processing | Working on the received data | Calculating numbers |
| Storage | Saving data and information | Saving a document |
| Output | Showing the result | Displaying the answer |

### Real-Life Example

Imagine opening a calculator application and calculating `10 + 20`.

1. You enter `10 + 20` using the keyboard.
2. The computer receives your input.
3. The CPU processes the calculation.
4. The result, `30`, appears on the screen.

This is a simple example of how a computer works.

---

## 2. Hardware vs. Software

A computer system has two major parts: **Hardware** and **Software**.

### 2.1 Hardware

Hardware refers to the physical components of a computer that we can see and touch.

**Examples:**

- CPU
- RAM
- SSD
- Motherboard
- GPU
- Keyboard
- Mouse
- Monitor

**Example:** A keyboard is hardware because it is a physical device that we can touch and use to enter information.

### 2.2 Software

Software refers to programs and instructions that tell computer hardware what to do.

**Examples:**

- Windows
- Linux
- Google Chrome
- Microsoft Word
- Visual Studio Code

**Example:** Google Chrome is software because it is a program that allows us to browse websites.

### Hardware vs. Software Comparison

| Hardware | Software |
|---|---|
| Physical components | Programs and instructions |
| Can be touched | Cannot be physically touched |
| Performs operations under program control | Provides instructions and functionality |
| Example: Keyboard | Example: Windows |

### How Do They Work Together?

Hardware and software depend on each other to provide useful computer functionality.

For example:

1. You click the mouse (hardware).
2. The operating system receives the action (software).
3. The CPU processes the required instructions.
4. The monitor displays the result (hardware).

**Remember:** Hardware provides the physical resources, while software provides the instructions that use those resources.

## 3. Input–Processing–Output (IPO) Cycle

The **IPO Cycle** explains how a computer receives information, processes it, and produces a result.

### Basic IPO Diagram

```text
       INPUT
         |
         v
    PROCESSING
         |
         v
       OUTPUT
```

### 3.1 Input

Input is the data or instruction provided to a computer.

**Examples:**

- Typing using a keyboard
- Clicking using a mouse
- Speaking into a microphone

### 3.2 Processing

Processing means performing operations on the received data according to program instructions.

The CPU is the primary component responsible for executing these instructions.

**Examples:**

- Adding two numbers
- Comparing two values
- Processing an image

### 3.3 Output

Output is the information produced after processing.

**Examples:**

- Showing information on a monitor
- Playing sound through speakers
- Printing a document

### Practical Example: Typing a Message

```text
You type a message
        |
        v
Keyboard sends input
        |
        v
Computer processes the input
        |
        v
Message appears on the monitor
```

**Important:** Storage is another major computer function. A computer can save input, output, programs, and other information for future use.

---

## 4. Key Takeaways

- A computer accepts input, processes data, stores information, and produces output.
- Hardware means the physical components of a computer.
- Software means the programs and instructions that use computer hardware.
- Hardware and software work together.
- The IPO cycle consists of Input, Processing, and Output.
- Storage is also an important function of a computer.
