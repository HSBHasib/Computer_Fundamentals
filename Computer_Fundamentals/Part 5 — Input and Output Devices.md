# 05. Input and Output Devices

### Understanding How Users Communicate with Computers

Input and output devices allow users to interact with computers.

- **Input devices** send data and instructions to the computer.
- **Output devices** present processed information to the user.

---

## 1. Input Devices

Input devices allow users to provide data and instructions to a computer.

They act as the communication channel from the user to the computer.

### 1.1 Common Input Devices

| Device | Purpose |
|---|---|
| Keyboard | Enter text, numbers, and commands |
| Mouse | Point, click, and select items |
| Microphone | Capture sound and voice |
| Scanner | Convert physical documents into digital data |
| Webcam | Capture images and video |
| Touchscreen | Accept touch-based input |

### 1.2 Real-Life Example

When you type your name using a keyboard:

1. You press the keys.
2. The keyboard sends the input to the computer.
3. The computer processes the input.
4. Your name appears on the screen.

**Remember:** Input devices send information into the computer.

---

## 2. Output Devices

Output devices present processed information to the user.

They act as the communication channel from the computer to the user.

### 2.1 Common Output Devices

| Device | Purpose |
|---|---|
| Monitor | Displays text, images, and videos |
| Speaker | Produces sound |
| Printer | Produces physical copies of documents |
| Projector | Displays images on a larger surface |
| Headphones | Provide audio output |

### 2.2 Real-Life Example

When you play a video:

1. The computer processes the video data.
2. The monitor displays the video.
3. The speakers produce its sound.

**Remember:** Output devices deliver information from the computer to the user.

---

## 3. Input vs. Output Devices

| Input Devices | Output Devices |
|---|---|
| Send data to the computer | Present information from the computer |
| User → Computer | Computer → User |
| Keyboard, mouse, microphone | Monitor, speaker, printer |

---

## 4. Key Takeaways

- Input devices send data and instructions to a computer.
- Output devices present processed information to users.
- A keyboard, mouse, microphone, scanner, and webcam are examples of input devices.
- A monitor, speaker, printer, projector, and headphones are examples of output devices.
- Input and output devices make communication between users and computers possible.
